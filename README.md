# CIS 5210

Python projects from a graduate course in artificial intelligence. This repository is private.

1. **Python basics.** List, string and generator exercises, plus a polynomial class. `homework1_alt.py` is a second version of the same assignment.
2. **Search.** N Queens with backtracking, and Lights Out and linear disk puzzles solved with breadth first search. Includes a Tkinter GUI.
3. **Informed search.** A tile puzzle solved with iterative deepening and A*, grid path finding with A*, and the disk puzzle with a custom heuristic. Includes GUIs.
4. **Game search.** A dominoes game player using alpha beta pruning. Includes a GUI.
6. **Markov decision processes.** Value iteration and policy iteration agents, plus parameter tuning for gridworld policies.
7. **Reinforcement learning.** Tabular Q learning with epsilon greedy exploration, and approximate Q learning with feature weights.
9. **Perceptrons.** Binary and multiclass perceptrons applied to the Iris and handwritten digit data sets, plus feature design for two mystery data sets.
10. **LLMs.** A notebook on prompting, using hosted and local models, and fine tuning. `homework10_alt.ipynb` is a second version.

The GUI files and parts of each assignment come from the course starter code. API keys in the notebooks were removed before upload.
